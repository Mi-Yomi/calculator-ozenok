# Калькулятор оценок АУЭС

Расчёт ТК, рейтинга допуска и итоговой оценки по предоставленному регламенту АУЭС 2026 года «Проведения рубежных контролей успеваемости и выставления рейтинга допуска обучающимся».

Источник сверки: `Регламент_2026_русский_06_10_1791376546_368428.docx`, предоставленный владельцем проекта. Соответствие проверено по этому документу; дату вступления в силу и наличие более поздних редакций калькулятор не определяет.

## Правила расчёта

- ТК по виду занятий = сумма оценок / количество оценок в соответствующем периоде. НП исключается из числителя и знаменателя; НЯ и не выставленные в срок оценки учитываются как 0.
- Расчёт охватывает весь выбранный период. Пустые ячейки считаются нулями. Недели без запланированного оценивания отмечайте НП. Будущие недели делают результат предварительным; календарь и сроки Platonus автоматически не отслеживаются.
- Коэффициенты ТКобщ взяты из таблицы 1, в порядке лекции / практика / лаборатории / СРОП: все занятия — 0,2 / 0,3 / 0,3 / 0,2; без лабораторий — 0,3 / 0,5 / 0 / 0,2; без практики — 0,3 / 0 / 0,5 / 0,2; только практика и СРОП — 0 / 0,9 / 0 / 0,1; только лекции и СРОП — 0,5 / 0 / 0 / 0,5. СРОП в интерфейсе обозначает работу с преподавателем соответствующего уровня обучения (СРБП/СРМП/СРДП).
- Р1 = 0,7 × ТК1общ + 0,3 × РК1; Р2 = 0,7 × ТК2общ + 0,3 × РК2; РД = (Р1 + Р2) / 2.
- Допуск: каждый РК > 0, среднее двух РК ≥ 50, РД ≥ 50, завершение всех видов занятий. Завершение подтверждается пользователем отдельно. Неверные оценки блокируют расчёт допуска.
- Автомат: допуск, каждый РК ≥ 50, посещаемость 100%, все задания выполнены в срок, нет нулей за задания. Преподаватель вправе выставить ИК = РД; кнопка принимает уже предложенный преподавателем автомат. При несогласии пользователь может ввести экзаменационную оценку.
- ИО = 0,6 × РД + 0,4 × ИК. Шкала содержит D (50–54), C+ относится к «Хорошо». Регламент не задаёт округление: пороги сравниваются с неокруглённым результатом; числа в интерфейсе показываются с одним десятичным знаком. Отдельный минимальный экзаменационный балл для применения формулы в документе не указан и не добавлялся.
- Нормы количества оценок за семестр: лекции — 4, включая два РК; СРОП — 2; практика и лаборатории — не менее 10. Число оценок показывается для проверки журнала, без дополнительных порогов допуска. НЯ/просроченный ноль — оценка; НП — нет. Один ввод в ячейке соответствует одной оценке.
- ТК выставляется до 23:59 среды следующей недели, РК — до 23:59 субботы рубежной недели по академическому календарю. FX допускает одну пересдачу экзамена без повторного изучения, F требует повторного изучения; апелляция подаётся в течение 24 часов после выставления оценки.

Сохранены границы недель исходного проекта: семестр 1–7 / 8–15, триместр 1–5 / 6–10. Документ не задаёт эти границы и отдельные нормы для триместра; сверяйте их с академическим календарём.

## Сохранённые данные и отчёты

Существующие оценки в localStorage сохраняются и пересчитываются по новым правилам. Для старых данных флажки завершения, посещаемости и выполнения заданий по умолчанию выключены. CSV сохраняет эти подтверждения в трёх дополнительных столбцах; старые CSV доступны для импорта. HTML-отчёт использует те же формулы и условия допуска.

Проверка порога ИО ≥ 70 сохранена как ориентировочный инструмент. Предоставленный регламент не устанавливает условия назначения стипендии. Положительный общий результат показывается только при известных ИО всех добавленных предметов; неизвестный результат не считается успешным.

## Запуск и проверка

Требуется Node.js 22.12+ (для Vite 8).

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
```

Проверки используют встроенный `node:test`, без новых зависимостей. Для GitHub Pages сохранён `base: '/calculator-ozenok/'`.
